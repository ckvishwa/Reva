# contracts/

JSON Schemas and the capability registry that Core, the apps and the Kernel share.

This directory is a byte-for-byte copy of `docs/spec/REVA_v2.0/08_CONTRACTS/`. CI (contracts lane) fails if the two differ and validates every `*.schema.json` as a JSON Schema. Edit both together until the spec pack is frozen; after that `contracts/` is the working copy and the spec copy is the record.

`native-agent-v1.REFERENCE-ONLY.proto` is reference material only, not a supported interface.
